# Skills

A skill is a self-contained folder with one job and a `SKILL.md` file that tells an AI agent exactly how to do it — when to use it, what steps to follow, and what rules never to break. Each skill lives in its own subfolder here (`skills/<skill-name>/SKILL.md`), so skills stay portable and easy to add, remove, or share independently. Skills live here as the canonical source. Claude Code reads them from `.claude/skills/` and Codex from `.agents/skills/`, both generated as mirrors of this folder. Gemini CLI and OpenCode read this folder directly, because the rulebook points them here. For the full curated catalog of skills — core and community — see `manifest/skills.md`.
