AI SecondBrain Stack

A git-versioned second brain for AI coding agents — Claude Code, Codex, Gemini CLI, OpenCode. Switch agents anytime; they all follow the same rules.

Claude Code

  1. Install Claude Code: curl -fsSL https://claude.ai/install.sh | bash — see the official docs.
  2. Create a new, dedicated, empty folder for your second brain and open it in your terminal. Don't point it at an existing project — give it a clean home of its own.
  3. Launch claude in that folder, then copy the Bootstrap Prompt below and paste it in.

    
    
Your agent takes over from here.

One-paste bootstrap

      
You hand your agent a single prompt and it becomes the installer. It checks your environment and reads the setup instructions on its own.

    

    

      
Interview-driven structure

      
Your agent interviews you about what you actually work on. The vault it builds reflects your answers instead of a generic template.

    

    

      
Skills that every agent finds

      
Skills live in the vault, not in one agent's private config. Claude Code, Codex, Gemini CLI, and OpenCode all read the same rulebook.

    

    

      
MCP with keys kept outside the vault

      
Only the servers you ask for get wired up. API keys stay in your agent's own config, never in a note and never in a commit.

    

    

      
Optional backup planning

      
Optionally plans a backup around the storage you already pay for. It only points you at something new when nothing you own fits the job.

    

    

      
Monthly maintenance

      
A recurring routine keeps the rulebook, skills, and adapters current as agents and tools change. You run it, your agent does the update.

    

    

      
Project codes

      
Every project gets a short code that never changes. Scheduled jobs, logs, branches, and commits carry it, so you can always tell what they belong to.

    

    

      
Parallel sessions without collisions

      
Run two agents at once without one committing the other's work. Code repos get a worktree per session, the vault gets named staging.
